# CoalVision Command Center

Interactive SIH demo implementation for a multi-modal coal transportation intelligence platform.

## Run locally

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`. The application includes the landing page, dashboard, tactical tracking map, CCTV/YOLO view, shipment list and deep dive, fleet, railway, port, route intelligence, analytics, alerts, integrations, administration, and reports routes.

The live simulation is deliberately self-contained: no external data source or map token is required for the demo.
